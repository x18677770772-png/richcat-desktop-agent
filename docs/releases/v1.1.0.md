# RichCat v1.1.0 发布说明

> 翡翠鎏金高端视觉改版 · RichCat 品牌统一 · 版本管理体系建立
>
> **发布日期**：2026-08-19 ｜ **git tag**：`v1.1.0` ｜ **上一版本**：v1.0.0

---

## 一、本版本核心变化

### 🎨 1. 全新高端视觉设计系统「翡翠鎏金 Jade & Gold」

- 墨夜底 `#080a12`（带蓝紫倾向，非纯黑）+ 右上翡翠 / 左下鎏金氛围光晕
- 品牌渐变 `#34d399 → #10b981 → #d4af37`（翡翠 → 深翡翠 → 鎏金）
- 玻璃拟态：渐变描边卡片、内高光、分层阴影、毛玻璃
- 动效：启动按钮流光扫过、状态点呼吸光、卡片 fade-in-up、hover 上浮
- 完整设计规范：`docs/ui-redesign-design.md`

### ✏️ 2. 品牌统一为 RichCat（替换 SightFlow 字标）

- 全窗口统一「猫图标 + RichCat 渐变发光字标」
  - 主界面头部 / 设置侧栏 / 客户窗口 / 记忆窗口 / 知识库窗口
- 修复原 logo 图标区多余的「R」字母偏差
- 新增纯猫图标 `src/renderer/src/assets/richcat-icon.png`

### 📦 3. 版本管理与版本隔离体系（本版本开始）

- 新增 `CHANGELOG.md`、`docs/versioning.md`、`docs/releases/`
- git tag：`v1.0.0`（改版前基线）+ `v1.1.0`（本版本）
- 目的：每次更新可追溯、可定位、可回滚
