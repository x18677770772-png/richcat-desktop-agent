# Release Notes · v2.0.0-alpha.2

> 财听猫 RichCat ｜ 2026-08-20 ｜ 预发布（alpha）
> 本版本在 v2.0.0-alpha.1 企业版切片基础上，接入**总后台遥测**，使真实终端可以把用量/心跳/报错上报到中央控制面。

---

## 一、本版本新能力

### 1. 总后台 Agent 遥测（终端 → 控制面）
- **心跳**：每 60s 上报一次，携带系统资源（CPU/内存/磁盘）、微信登录态、版本。
- **用量**：每 10min 批量上报，携带会话/消息/自动回复/接管/API 调用计数。
- **错误**：实时上报结构化错误码（崩溃/会话丢失/模型超时等），触发控制面告警。
- **离线缓冲**：断网时本地缓存（上限 5000 条），恢复后自动补发（带 `replayed` 标记）。
- **合规**：只上报用量统计/心跳/错误码，**不含聊天内容与客户个人信息**；设备标识 HMAC 脱敏。

### 2. 企业版面板「总后台接入」配置
- 设置窗口 → 企业版 → **总后台接入** 区块：
  - 后台地址（默认 `https://129.226.204.240:8443`）
  - 站点 Token（后台创建企业时生成）
  - 启用开关 + 保存 + 立即补发
  - 连接状态徽标（已连接/未启用）

### 3. 中央管理后台代码库（control-plane/）
- Go+Gin 多租户后端：认证（JWT+bcrypt+RBAC+失败锁定）/ 遥测接入 / 舰队视图 / 告警 / 计费 / 超管管理
- React 管理后台 Web：登录 / 舰队 / 用量看板 / 告警中心 / 计费 / 超管平台
- docker compose 部署 + nginx HTTPS 反代 + 安全基线

---

## 二、如何启用终端上报

1. 安装本版本。
2. 打开中央管理后台 `https://129.226.204.240:8443`（超管登录，见部署 .env 的 ADMIN_EMAIL/PASSWORD）。
3. 超管页「建企业」，记下返回的 **site_token**。
4. app 设置 → 企业版 → 总后台接入：填后台地址 + site_token + 启用，保存。
5. **重启引擎**（遥测随引擎启停），后台舰队视图即可看到该终端在线。

## 四、已知限制（预览版）

- 授权码为本地占位校验（正式版接服务端在线授权）
- 密钥为本地静态加密（非 KMS/DPAPI）
- 审计无哈希链（append-only 基线）
- 遥测上报需引擎运行；控制面域名后置（当前 IP 直连 + 自签证书）
