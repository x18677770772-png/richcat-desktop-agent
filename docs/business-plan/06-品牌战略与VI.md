**目的**：为全新 to B 品牌「财听猫 RichCat」从零建立企业级信任的品牌体系——品牌定位与价值主张、命名体系（主品牌/副线关系）、可执行的 VI 规范、品牌故事与口号、官网结构与转化要点、品牌资产清单。让每一个对外触点（官网、报价单、白皮书、PPT、IP 形象）讲同一个品牌故事。
**原则**：不卖工具，卖业务结果；品牌资产全部挂靠在「降本增效 + 合规信任」的企业价值主张上；IP 形象做温度，VI 体系做专业。

## 0. 执行摘要（先给结论）

1. **品牌一句话**：财听猫 = 一家「看得见、记得住、敢合规」的 AI 客户服务与管理系统。**看得见**（纯视觉驱动，不依赖任何微信接口/协议）、**记得住**（客户画像 + 工作记忆双引擎）、**敢合规**（视觉路线是个人号×群聊生态位里唯一大体量合规方案）。
2. **品牌定位**：面向依赖个人微信/群聊做客服与销售的**中小微及中型企业**，用 AI 提供「7×24 真人级接待」，以「少招客服、回复提速、客户被记住、情绪风险不漏」的 ROI 账成交。定位语：**「个人号×群聊生态位上，唯一把『合规、群聊、AI 记忆』三者做全的客服系统」**。
3. **命名体系**：主品牌 **财听猫 RichCat**（产品品牌，一切商业触点使用）；副线 **财听见**（技术能力品牌，仅用于开源/技术白皮书/开发者社区，且必须标注从属关系「财听猫家族 · 感知与记忆内核」）。**销售物料禁用「财听见」独立出现**。
4. **VI 基调**：「深空蓝 × 琥珀金 × 听声青」三色体系——深空蓝扛企业信任，琥珀金扛财富与温度，听声青扛 AI 智能；字体统一「阿里巴巴普惠体 + Inter」；IP 猫形象做品牌温度，VI 体系保证专业可信。本规范可直接执行（见 §3 清单）。
5. **官网 = 自助信任机器**：5 大版块（首页/产品/案例/定价/合规）+ 转化三件套（首屏 ROI 一句话、信任凭证区、ROI 计算器 + 在线客服自证）。**官网客服直接用财听猫自己接**——最好的秀肌肉。
6. **90 天落地节奏**：第 1 周定稿 VI 与官网骨架 → 第 2 周产出全部品牌资产（Logo SVG/反白、IP 形象包、PPT/报价模板、安全白皮书）→ 第 4 周官网上线并接入财听猫在线接待 → 之后所有销售物料按本规范统一出街。

## 1. 品牌定位与价值主张

### 1.1 品牌基础（Brand Foundation）

| 维度 | 内容 |
|---|---|
| **品牌目的（Why）** | 让每一个依赖微信生态做生意的人，不再被客服深夜困住——AI 替真人做重复接待，真人只做需要判断的事。企业的人力成本降下来，客户满意度升上去。 |
| **品牌愿景（Where）** | 成为微信/企微生态上中小微企业的「AI 客户服务事实标准」：7×24 无人值守的高质量接待，像水电一样可靠。 |
| **品牌使命（What）** | 为企业提供看得见、记得住、敢合规的 AI 客户服务与管理系统，交付「客服人力降 50%、响应从 2 小时到 2 分钟、客户被记住、风险不漏判」的业务结果。 |
| **品牌价值观（How）** | ① **客户生意优先**：一切功能围绕成交与口碑，不为炫技做功能；② **合规是生命线**：纯视觉路线 + 防封策略，绝不碰外挂；③ **越用越懂你**：工作记忆沉淀业务 know-how；④ **透明可审计**：全链路留痕、可导出、可脱敏；⑤ **人机协同**：AI 干粗活，人干需要判断的活。 |
| **品牌个性（Persona）** | 像「猫」一样**警觉**（每条消息、每个情绪风险都不放过）、**温润**（懂客户情绪价值，不冷冰冰）、**可靠**（7×24 值守，说到做到）；同时像「同事」一样**专业**（to B，讲 ROI、讲合规，不浮夸）。 |

### 1.2 目标受众与购买触发

- **决策人**：老板/操盘手本人（SMB）或客服负责人/私域运营总监（中型企业）；IT/法务有一票否决权（采购触点必须覆盖其关注点）。
- **购买触发事件**（与 04 销售打法对齐）：
  - 客服人力成本高、夜班无人值守、回复慢导致客户流失；
  - 多账号管理混乱、客户无建档无记忆、复购靠运气；
  - 客诉/退款/投诉情绪风险漏判，口碑受损；
  - 个人号×群聊场景，官方 iLink 只能 1v1、企微外部群不可用、外挂工具封号风险极高——**没得选**。
- **核心 ICP**：私域电商/社群团购操盘手、知识付费/训练营 IP、医美/口腔/体检门诊、保险/汽车/房产销售团队、MCN 达人商务。

### 1.3 品牌定位声明

> **对** 依赖个人微信/群聊做客服与销售的中小微及中型企业，
> **财听猫 RichCat** 是一个 **7×24 真人级 AI 客户服务与管理系统**，
> 它 **通过纯视觉自动操作（像真人一样看屏幕、敲键盘、记笔记），不依赖任何微信接口/协议**，
> 提供 **客户自动建档与长期记忆、工作记忆引擎、群聊接待、情绪风险识别、人工接管**，
> 因为 **它看得见、记得住、敢合规**，
> 所以 **企业可以少招客服、回复提速 60 倍、客户被记住、投诉不漏判**——把客服从重复劳动中解放出来。

### 1.4 价值主张（三大支柱 × ROI 话术）

**支柱一：看得见——合规的自动化（合规红利，头号差异化）**
- 纯视觉 VLM 驱动（截图→识别→自动操作），不走 Hook/协议逆向，不碰个人微信风控红线；这是「个人号×群聊」生态位里唯一大体量合规方案（WeTool 已两次封禁、个人微信机器人全部外挂化）。
- 适配微信/企业微信/钉钉/飞书桌面端，像真人一样操作。
- **ROI 话术**：「别人在封号边缘帮你回消息，财听猫在合规线上替你值守——这单生意没有『封号归零』的风险。」

**支柱二：记得住——客户画像记忆 + 工作记忆双引擎（业务层差异化）**
- 客户自动建档 CRM + 跨会话长期记忆：客户被记住，复购率、客单价、VIP 体验直接提升。
- 工作记忆引擎（过程性/经验记忆）：记住「为什么这么操作、哪些操作失败了、人工接管后如何改进」，客服 Agent 越用越懂你的业务——**这是「记住怎么干活」，与行业普遍「记住客户是谁」的画像记忆不重叠，是真实业务护城河**。
- **ROI 话术**：「行业都在做『记住客户』，财听猫多做了一层——记住怎么把客户服务好。它的经验，会沉淀成你公司的资产。」

**支柱三：敢合规——企业级信任（成单的临门一脚）**
- 全链路操作/对话留痕、审计日志、可导出可脱敏；私有化部署（MSE）数据不出内网；承诺可用率 ≥ 99%、告警 ≤ 15 分钟 SLA；提供安全白皮书、数据隐私承诺书。
- **ROI 话术**：「IT 与法务的一票否决，财听猫在 Demo 第一场就替你答完了——部署手册、安全白皮书、审计演示，三件套齐活。」

### 1.5 品牌核心承诺（Brand Promise）

> **「财听猫替你看好每一单生意。」** —— 客户可以始终期待：消息不遗漏、客户被记住、风险被预警、人工随时接管、数据留痕可审计。24 小时 × 7 天，从未打烊。

## 2. 命名体系：财听猫（主）/ 财听见（副线）

### 2.1 命名结构与关系

| 层级 | 名称 | 英文 | 角色 | 使用边界 |
|---|---|---|---|---|
| **主品牌 · 产品品牌** | **财听猫** | **RichCat** | 面向企业客户的产品品牌——AI 企业级客户服务与管理系统 | 一切**商业触点**：官网、定价、报价单、合同、PPT、销售物料、客服号、案例、广告、产品界面（关于/设置/日报署名） |
| **副线 · 技术能力品牌** | **财听见** | **CaiTingJian / RichSence（内部建议）** | 「听」+「看」的感知与记忆内核——VLM 纯视觉驱动层 + 工作记忆引擎的技术身份 | **技术/社区触点**：开源仓库、技术博客、开发者文档、SDK、招聘 JD、技术白皮书署名 |

**关系定义（一句话）**：
> **财听猫是「形」，财听见是「芯」。** 财听猫产品由财听见内核驱动——财听见负责「看见屏幕、听见需求、记住经验」，财听猫负责「为企业交付服务结果」。二者是「内核—产品」从属关系，不是平行产品线，更不是两个品牌各自独立卖货。

### 2.2 命名边界规则（可直接执行的 5 条）

1. **商业销售场景只用「财听猫 RichCat」**。官网、报价单、合同、Demo、案例、广告、客服话术中，品牌名一律为「财听猫（RichCat）」；「财听见」不得独立出现在面向企业决策者的销售物料上。
2. **技术场景可用「财听见」，但必须挂从属**。开源仓库/技术博客/开发者文档出现「财听见」时，首段必须标注「财听见是财听猫 RichCat 的技术内核品牌」，Logo 区域同时出现财听猫字标或「财听猫家族」字样。
3. **副线不对外单独报价**。财听见不设独立定价、不单独销售；它只以能力形态出现（如 MSE API v1、私有化内核授权），对外报价永远挂「财听猫 MSE」。
4. **品牌资产同源**。财听见使用与财听猫同一套色彩/字体/图形系统（见 §3），只允许在辅助图形上强调「听声弧 + 取景框」的感知主题，不得另立视觉体系。
5. **IP 形象归属主品牌**。财猫（吉祥物）是财听猫 IP，可在技术博客中以吉祥物形式出现，但署名与落地页必须回链财听猫官网。

### 2.3 命名故事（为什么叫「财听猫」）

- **财**：为生意而来，招财、旺生意——to B 用户第一联想「这工具帮我把钱赚明白」。
- **听**：听得见每一个客户需求、每一句情绪、每一次投诉预警；「听」是服务起点。
- **猫**：像猫一样警觉（不放过每条消息/每个风险）、有温度（情绪价值、人感）、且是「招财猫」的天然品牌锚点——**可记忆、可萌化、可延展**（表情包、IP 形象、吉祥物）。
- **RichCat**：Rich（财富/丰盈）× Cat（猫）——英文世界直接传达「帮你赚钱的猫」，简短好记，且域名/资产上「RichCat」无歧义。

## 3. VI 规范（可直接执行）

> 以下规范为 v1.0，落地顺序见 §3.7 检查清单。所有色值为目标值，设计落地时需以品牌指南 PDF 输出最终校准版（含 CMYK/潘通参考）。

### 3.1 Logo 系统

| 项目 | 规范 |
|---|---|
| **主 Logo** | 组合式：IP 猫头剪影（图形）+ 中文「财听猫」+ 英文「RichCat」。图形居左，中文在上、英文在下（竖排组合）；或中文 + 英文横排（横幅组合）。**优先使用中文主字标**，英文为辅助识别。 |
| **Logo 变体** | ① 全色版（深空蓝 + 琥珀金 + 听声青，透明底）；② 反白版（白色图形与文字，用于深色底/产品深色界面）；③ 单色版（纯深空蓝或纯白，用于印章/水印/雕刻）；④ 图标版（仅猫头剪影，用于 favicon、应用图标、头像、胶囊位）；⑤ 渐变版（仅限官网 Hero/发布会大屏等品牌大版面，常规物料禁用）。 |
| **安全空间** | Logo 四周保留 ≥ 0.5 倍 Logo 高度（以最高字形为基准）的留白，任何文字、图形、图片不得侵入。 |
| **最小尺寸** | 全色组合 Logo ≥ 120px（数字端）/ ≥ 25mm（打印）；图标版 ≥ 32px；< 32px 场景（favicon）只允许用图标版猫头。 |
| **使用禁忌** | 禁止拉伸变形/旋转倾斜/改色换色/添加描边或投影/放置于杂乱底图上/与竞品 Logo 并列/切分拆解/叠加渐变不透明。 |
| **文件清单** | 见 §6 品牌资产清单（PNG 透明底 1024px+、SVG 矢量、反白、单色、favicon、ico/icns）。 |

### 3.4 辅助图形系统（Auxiliary Graphics）

1. **猫耳剪影（Brand Mark）**：由 IP 猫头简化的几何猫耳+圆脸剪影，是 Logo 图形与 UI 图标的母体，所有图标/形状尽量从它演化。
2. **听声弧（Echo Arc）**：以猫耳为锚点的同心圆弧/声波曲线，代表「听」——用于卡片角标、加载动画、页面分隔、AI 对话中的「正在听」状态。
3. **取景框（Viewport Frame）**：四角取景线框，代表「看」——用于「截图→识别→操作」的视觉链演示、功能截图画框、案例页的操作可视化。这是财听猫最独特的技术语义，官网产品页核心视觉用它。
4. **金线（Wealth Thread）**：细金色描边/高光线，代表「财」——用于数据高亮、VIP 语义、成果数据。
5. **网格基底**：深空蓝底 + 细线网格 + 金线点缀，用于 PPT 封面、白皮书封面、官网大版面，建立「工程感 + 品质感」。

**辅助图形使用规则**：听声弧与取景框只做图形元素不做文字底纹；辅助图形饱和度与密度受控（大面积时降透明度至 10–20%），禁止喧宾夺主。

### 4.2 品牌故事（Brand Story，约 150 字，可直接用于「关于我们」）

> 很多生意的客服，都困在深夜的一台电脑前：消息一条接一条，客户在等着，漏掉一条就漏掉一单；客户明明聊过，下次却像第一次见面；投诉快爆了，自己还在忙着复制粘贴。
>
> 我们决定造一个「真人级的 AI 同事」——它像猫一样警觉，看得见屏幕上的每一条消息；像资深客服一样，记得住每一位客户、每一次改单、每一句承诺；更重要的是，它不碰任何灰色外挂，只靠「看屏幕、敲键盘、记笔记」的本分方式替你值守，7×24 小时，从不下班。
>
> 这就是财听猫。它替你看好每一单生意，让你从重复劳动里解放出来，去做只有人才能做的判断。

### 4.3 故事背后的品牌资产逻辑

- **猫 = 警觉 + 温度**：猫的形象承担「情感连接」与「记忆点」——to B 产品最容易冷冰冰，财猫 IP 是破冰点，也是表情包/口碑传播的载体。

- **合规 = 信任底座**：故事刻意强调「不碰灰色外挂、本分值守」——直接命中目标客户「想用又怕封号」的最大顾虑，把合规从卖点变成品牌基因。

### 5.4 合规红线（品牌不可碰的底线）

1. **不承诺「永不封号」**：合规是相对优势，不是绝对承诺；对外话术用「视觉路线风控相对较低、本分值守」，不做绝对化宣传。
2. **如实披露备案状态**：算法备案/生成式 AI 备案按网信办要求推进，官网「合规」页如实标注进展，绝不虚构徽标。
3. **数据隐私承诺可兑现**：白皮书写到的能力（脱敏/留痕/导出/私有化）必须在产品中真实可查，防止品牌与产品能力脱节。
4. **AI 输出责任**：明确 AI 回复留痕与人工审查兜底机制，客服场景涉及医疗/金融/法律内容时展示免责提示。
