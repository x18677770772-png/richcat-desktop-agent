## 0. 执行摘要（先给结论）

**结论一：按"坐席"授权，不按"后台登录账号"授权。** 坐席 = 一个值守客服账号（微信/企微）在一台值守机上的 7×24 值守能力。它是"成本单元"（每账号有 LLM/VLM API 成本）也是"价值单元"（每账号替代约 0.5–1 人夜班/节假日值守）。后台登录用户是"使用人数"，含在套餐内并限量，不作为主授权单位。

**结论二：四态授权 + 在线心跳 + 离线宽限。** 试用（14 天）→ 正式（1 年）→ 续费 / 过期；离线授权作为断网/内网客户备用通道。Agent 每 5 分钟心跳上报云管 License 服务，断网后 72 小时离线宽限，超时降级为"仅人工接管 + 数据只读"，防扩散与防白嫖靠设备指纹绑定 + 并发心跳校验。

**结论三：套餐以 ¥2 万/年（5 坐席）为标准锚，¥1 万/年 战略伙伴版为冷启动种子价（前 10 家、标准价 5 折）。** 上层设专业版 ¥4.5 万/年（15 坐席，含云管 Pro）与旗舰版 ¥8 万/年（30 坐席，含云管旗舰），用"整包折扣"制造升级动力。增量坐席 ¥3,600/坐席/年（¥300/月）。

**结论四：计量以"会话"为主单位，超量按量计费但目标是"回收成本 + 抑制滥用"，不是利润引擎。** 基础额度 10,000 会话/坐席/年（≈5 万条 AI 处理消息，对齐 03 基准 150 条/日×365）；超量 ¥0.08/会话（市场参考 ¥0.05–0.10 上沿，保 25% 毛利）；用量包预购锁折扣；硬封顶 = 基础额度 ×1.2，防 API 成本爆单。

**结论五：财听猫云管（托管中央后台）是独立溢价层。** 云管 Lite 随订阅赠送（激活/账号级配置/单账号看板）；云管 Pro ¥8,000/年（集中看板/告警中心/审计/月度报告/Webhook）与云管旗舰 ¥20,000/年（+学习沉淀/API 全量/SSO/SLA 承诺）是"从工具到运营体系"的升级钩子。

**结论六：90 天最小可收费闭环 = License（W1–3）→ 收款基础（对公/数电票/合同，W1–3）→ 云管 Lite（W3–6）→ 用量计量 v1（W6–8）→ 云管 Pro（W8–10）。** 计费链路（激活→付款→开票→签发 License）全部自动化或半自动化，不占创始人交付带宽。

## 1. 授权模型：按坐席授权 + 四态流转 + 心跳/离线校验

### 1.1 授权单位：为什么是"坐席"而不是"账号"

| 候选单位 | 定义 | 问题 | 判定 |
|---|---|---|---|
| 后台登录账号 | 登录云管控制台的人 | 只反映"几个人看"，不反映值守能力与成本；客户 1 人可管 20 号 | 不作为主单位 |
| 微信/企微账号 | 被值守的客服身份 | 客服常换号/换设备；账号是被自动化对象，无法绑定"能力" | 作为坐席的属性 |
| **坐席（值守账号）** | **1 个值守账号 × 1 台值守机 × 7×24 值守能力** | —— | **主授权单位** |

**坐席定义与绑定规则：**
- 1 坐席 = 1 个值守账号（微信/企微号）+ 1 台值守机（设备指纹）。同一时刻 1 坐席 = 1 账号 × 1 设备。
- 坐席可**解绑/换绑**客服账号（客服换号、账号迁移），换绑不增加坐席；设备换绑月度 ≤ 2 次（防扩散，见 §7）。
- 坐席数即**值守并发上限**：每坐席 1 个值守进程（继承 F8 多实例），账号内消息串行处理、会话排队；并发 = 已激活坐席数。
- 管理账号（控制台用户）随套餐限量：标准版 5 / 专业版 10 / 旗舰版 20；增购 ¥600/账号/年。

> **一句话**：客户买的是"N 个客服号的无人值守能力"，不是"N 个人登录系统"。按坐席授权 = 成本和价值同步收口。

### 1.2 授权四态流转

```
                    ┌──────────────────────┐
                    │  Community 开源社区版   │  免费、不接入 License（引流/口碑池）
                    └──────────┬───────────┘
                               │ 落地页注册（手机号 + 企业/营业执照验证）
                               ▼
                    ┌──────────────────────┐
                    │   Trial 试用（14 天）   │◄─ 试用 License：绑租户+首次设备
                    │   5 坐席全功能          │   每营业执照限 1 次（防薅，见 §7）
                    └──────────┬───────────┘
                               │ 到期前 T-3 天强提醒
              ┌────────────────┴────────────────┐
              │ 付费（对公/微信/银企直连）          │ 未付费
              ▼                                  ▼
     ┌──────────────────────┐         ┌──────────────────────┐
     │   Active 正式（1 年）  │         │   只读演示态           │
     │   坐席数 = 套餐数       │         │   AI 停，历史数据可查   │
     │   云管功能按套餐开 Flag │         │   接管通知保留          │
     └──────────┬───────────┘         └──────────┬───────────┘
                │ T-60/30/15/7/3 续费提醒         │ 付费后 5 分钟自动解锁
                ▼                                │
     ┌──────────────────────┐                    │
     │   Renewed 续费（+1 年）│◄───────────────────┘
     └──────────────────────┘
   （Active 到期未续 → 7 天宽限不停服 → D+7 停 AI 仅接管+只读 → 数据保留 30 天 → 归档/导出）

   离线授权（备用通道，云管旗舰专属）：
   ┌──────────────────────┐
   │  Offline 离线（固定有效期）│◄ 内网/断网客户：离线 License 文件
   │  签发+本地验签，防时钟回拨  │   到期人工续期文件；价格含管理服务费
   └──────────────────────┘
```

### 1.3 许可证校验：在线心跳 + 离线宽限

```
值守机 Agent ──每 5 分钟心跳（设备指纹 + 坐席ID + 时间戳）──▶ 云管 License 服务
     ▲                                                          │
     │  本地 License 文件（RSA 签名验签：到期日/坐席数/设备绑定）   │ 校验三件事：
     └────────────── 返回签名响应（有效 | 宽限 | 锁定） ◀─────────┘  ① 授权未过期
                                                                  ② 坐席数未超套餐
                                                                  ③ 设备指纹匹配
  断网（心跳中断）→ 进入 72h 离线宽限（服务不中断）
  断网 >72h       → 本地降级：AI 自动回复停，仅保留人工接管 + 数据只读
  恢复心跳        → 自动重校验、自动解锁
```

- **在线心跳校验**：正常态。Agent 每 5 分钟上报，服务端校验"授权有效 + 坐席未超 + 设备匹配"，返回签名响应；异常（多设备轮询/换设备/超并发心跳）→ 拒签 + 告警 + 锁定。
- **离线宽限**：断网不立即停服，给 72 小时缓冲（网络抖动/临时断线不影响客户体验）。宽限期内未恢复 → 降级"仅人工接管"，保护我方成本同时不让客户数据丢。
- **离线授权（Offline License）**：面向值守机无法出外网的客户（内网强管控），签发离线 License 文件，本地验签、固定有效期、防时钟回拨（记录最近运行时间戳，检测回拨即锁定）。因不可实时监控，离线授权仅作为云管旗舰增值，价格含管理服务费（见 §5）。

### 2.3 升级 / 降级路径与差额规则

```
降级方向（仅续费时生效，当期不退款）
  旗舰 ──▶ 专业 ──▶ 标准 ──▶ 战略伙伴（前 10 家外不可再选）
升级方向（任意时刻生效，立即到位）
  战略/标准 ──加购云管Pro──▶ 升专业意向 ──▶ 专业版
  专业 ──加购云管旗舰──▶ 旗舰版
  任意档 ──▶ 增购坐席（¥3,600/坐席/年 × 剩余天数折算）
```

**差额公式（升级，立即生效）：**
```
升级补差 = (新套餐年价 − 旧套餐年价) × 剩余天数 / 365
坐席增购费 = 增购坐席数 × ¥3,600 × 剩余天数 / 365   （不延长订阅到期日）
云管/管理账号加购费 = 加购单价 × 剩余天数 / 365
```

**规则：**
- 升级：按剩余天数比例折算已付金额抵扣新套餐，立即生效，坐席数/Flag 即刻到位；补差 ≥ ¥0。
- 降级：**只在续费窗口生效**，当期不退款；已购用量包滚动至新套餐（见 §6）。
- 月付→年付切换：按已付月费折算抵扣，差额补足。
- 实例：标准版已用 6 个月升专业版 → 补差 = (4.5万−2万) × 182/365 ≈ ¥12,466，即刻 15 坐席 + 云管 Pro。

## 3. 用量计量与超量计费：会话为主、成本闸门、配额封顶

### 3.1 计量维度（计什么，为什么）

| 维度 | 是否计费 | 口径 | 用途 |
|---|---|---|---|
| **会话（Session）** | ✅ 主计费单位 | 客户首条消息 → 连续 30 分钟无新消息 或 坐席关闭 → 1 会话；单客户同时只计 1 个活跃会话 | 客户可理解的计费单位 |
| AI 处理消息数 | 🔍 内部换算 | AI 实际调用次数（视觉识别 + 回复生成 = 1 次调用）；会话内 >20 条按 20 条计（防单客户刷量） | 内部成本核算，不对客户直算 |
| Token 成本 | 🔍 内部闸门 | 单次调用综合成本（VLM+LLM+记忆，目标 ¥0.02） | 成本监控，超限触发模型降级（见 3.4） |
| 接管次数（人工接管） | 📊 不计费 | F2 接管事件数 | 价值指标（进月度报告），证明"降人力" |
| 坐席数/账号数 | 订阅内 | 坐席授权数 | 已含在年费 |

> **为什么不按 token 对客户计费**：客户不认 token，且造成"用量恐惧"。对外按"会话"呈现，内部按"AI 调用次数 × 单次成本"核算，中间用"平均 3 次调用/会话"换算。

### 3.2 基础额度（年费含多少）

```
基础额度 = 10,000 会话 / 坐席 / 年  ≈  50,000 条 AI 处理消息 / 坐席 / 年
套餐基础额度 = 坐席数 × 10,000 会话 / 年
  标准版（5 坐席）= 50,000 会话/年
  专业版（15 坐席）= 150,000 会话/年
  旗舰版（30 坐席）= 300,000 会话/年
```
- 对齐 03 基准：150 条/日 × 365 ≈ 54,750 条/坐席/年，按平均 5 条/会话 ≈ 11,000 会话。取 **10,000 会话**作基准，覆盖典型私域客服 3–5 条/会话场景，留约 10% 余量。
- 战略伙伴版同标准版额度（5 万会话/年）。

### 3.3 超量计费（价格公式）

```
月度超量费用 = max(0, 当月实际会话 − 剩余基础会话) × ¥0.08 / 会话
预购用量包抵扣：先抵扣用量包会话，再计入超量现结
```

| 计费方式 | 单价 | 毛利率* | 说明 |
|---|---|---|---|
| 超量现结（月度账单） | **¥0.08/会话** | ≈25% | 市场参考 ¥0.05–0.10 上沿，抑制滥用 + 回收成本 |
| 用量包 1 万会话 | ¥680（¥0.068/会话） | ≈13% | 现结价 85 折，鼓励预购、现金流前置 |
| 用量包 5 万会话 | ¥3,000（¥0.06/会话） | ≈保本 | 大客户承诺/渠道单，战略性让利 |
| 内部换算参考 | 平均 3 次 AI 调用/会话 × ¥0.02 ≈ ¥0.06/会话 | —— | 成本闸门基准，非售价 |

\* 毛利率按内部会话成本 ¥0.06 估算；售价必须 ≥ 成本 ×1.25 是硬纪律（见 3.4）。

### 3.4 配额封顶防爆单（成本闸门 + 分级熔断）

```
单坐席日配额（软）  100 会话   ≈ 3.7× 基础日均（27）
单坐席月配额（软）  3,000 会话 ≈ 3.6× 基础月均（833）
租户硬封顶（硬）    = 套餐基础额度 × 1.2
```

| 触发点 | 行为 |
|---|---|
| 会话数 > 软配额 | ① 告警推送到管理者（企微/钉钉/飞书）；② 超出软配额的会话转入"待接管"队列，不再自动回复 |
| 持续高用量（超软配额 3 天） | ③ AI 回复降速（回复间隔拉长），防止账号异常刷量 |
| **达到硬封顶（基础额度 ×1.2）** | **④ AI 自动回复暂停，仅保留人工接管 + 数据只读；控制台一键"购买用量包/提升配额"解锁** |

**内部成本闸门（与 03 结论四联动，防止毛利被吃穿）：**
- 单次 AI 调用综合成本连续 7 日 > ¥0.03 → 触发国产模型优先路由审计；
- 单次成本 > ¥0.04 → 自动降级模型（高端 → 中端）或触发商务（BYOK/涨价/收紧配额）。

> **一句话**：配额与封顶保护的不是客户，是我们的 API 成本。超量计费本质是"成本回收 + 滥用抑制"，利润来源仍是订阅年费。

## 4. 产品内计费工作流：从激活到开票到账

### 4.1 激活流程（新客户，全程半自动）

```
落地页注册（手机号 + 企业/营业执照验证）
  → 创建企业租户，自动签发 14 天试用 License
  → 下载值守机 Agent（Windows 安装包，签名）
  → 安装 → 登录客服账号（微信/企微）
  → 控制台生成激活码 → Agent 绑定设备指纹 + 账号
  → 心跳上报 → 试用 License 生效 → 开始值守
付费解锁（试用中或到期后）：
  控制台一键下单 → 对公转账 / 微信支付 / 银企直连
  → 财务确认到账（≤1 工作日）→ License 服务自动签发正式 License
  → Agent 5 分钟内全功能解锁 → 开票并行（不阻塞上线）
```

### 4.2 试用 14 天 → 付费解锁

- 试用期最后 3 天：控制台 banner + 短信/微信提醒"剩余 N 天；年付 ¥2 万解锁，前 10 家战略伙伴 ¥1 万"。
- 到期未付费：进入**只读演示态**——AI 自动回复停止，历史客户/会话可查看，接管通知保留；付费后 5 分钟内恢复全功能（数据不丢，无需重新配置）。
- 试用转正式**无缝**：不重新注册、不重新绑定设备，仅签发正式 License 覆盖试用。

### 4.3 到期 / 欠费 / 超量行为矩阵

| 场景 | 时间点 | 行为 |
|---|---|---|
| **到期未续费** | T-60/30/15/7/3/1 天 | 多级提醒（控制台 + 企微机器人 + 短信 + 销售/CS 跟进） |
| | D0（到期日） | 进入 7 天宽限期，服务不中断，标注"即将停服" |
| | D+7 | 停 AI 自动回复，保留人工接管 + 数据只读 |
| | D+37 | 数据归档/按合同处理（可导出），坐席释放 |
| **欠费（对公账期客户）** | 账期 > 30 天 | 云管告警 + 停服倒计时 3 天；3 天后 AI 停 + 数据只读 |
| | 企业单首付 < 40% | **不启动实施**（03 纪律，签约即写进合同） |
| **超量** | 软配额/硬封顶 | 见 §3.4 分级熔断 |

> **商业纪律（对齐 01/03）**：年付优先、账期 ≤30 天、超期停服；试用不放水（14 天强制付费解锁）；任何"免费/低价换案例"只限战略伙伴前 10 家，其余一律按价。

### 4.4 对公收款与发票开票

| 环节 | 规则 |
|---|---|
| 收款通道 | 对公基本户（D1–3 办妥）+ 微信支付/支付宝商户号 + 银企直连（后续）。to B 主用对公转账 |
| 到账确认 | 财务每日对账，到账后 ≤1 工作日签发 License；到账与开票解耦，不阻塞客户上线 |
| 开票类型 | 增值税专用发票（一般纳税人）/ 普通发票；以**数电票（电子发票）**为主 |
| 开票时效 | 数电票即时/当天；专票 3 个工作日；抬头须与合同主体一致 |
| 发票流程 | 付款 → 对账 → 开票 → 邮箱/税局平台送达；企业单按合同里程碑开票 |
| 分期收款 | 企业单（如有）：首付 ≥40% 开工，实施/上线款 + 尾款按里程碑（对齐 03 回款纪律） |

## 5. 财听猫云管：中央后台如何成为可收费溢价层

### 5.1 定位：从"工具"到"运营体系"

单账号值守的价值是**客户看不到的**（AI 在后台默默回复）。云管把价值变成**管理者看得见的资产**：集中看板、实时告警、审计留痕、月度报告、学习沉淀。这是把"软件采购"升级为"服务采购"的定价基础，也是 demo 时决策者眼睛看的第一个东西（对齐 02 G3）。

### 5.2 云管三级定价（独立溢价层）

| 档位 | 定价 | 能力 | 卖点语言 |
|---|---|---|---|
| **云管 Lite** | 随订阅含 | 激活/License、账号级配置、单账号看板、基础告警（本账号宕机/接管） | 开箱即用的底座 |
| **云管 Pro** | **¥8,000/年**（标准版加购） | 多账号集中看板、实时告警中心（企微/钉钉/飞书机器人：宕机/风险/接管/超量）、全链路审计（可导出/脱敏）、月度服务报告、Webhook 推送、值班表与接管队列 | "老板看到 AI 在保护客户关系；法务过得了审计闸门" |
| **云管旗舰** | **¥20,000/年**（专业版加购） | 云管 Pro 全部 + **学习沉淀**（跨账号工作记忆聚合、共享知识库/话术库、话术 A/B）、开放 API 全量、SSO/企业微信登录、SLA 月度可用率承诺（≥99%）、专属客户成功经理 | "AI 越用越懂你的业务，且可度量可承诺" |

> **捆绑逻辑**：专业版含云管 Pro（值 ¥8,000），旗舰版含云管旗舰（值 ¥20,000）——整包折扣制造"升专业/旗舰比逐项加购划算"的认知（见 2.3 差值示例）。

### 5.3 引导升级的四个触发点

1. **告警演示**（试用期）：让客户看到"宕机/风险/接管"实时推送到老板手机——试用期就演示告警中心，触发对 Pro 的渴望。
2. **月度报告**（T+30）：交付时主动送第一份月度服务报告（响应时长/接管率/满意度/转化线索），老板要数据 → 需要 Pro 持续产出。
3. **审计需求**（企业采购）：法务/合规闸门一问审计，只有 Pro/旗舰有全链路可导出审计 → 商务抓手。
4. **多账号扩张**（第 6 个坐席起）：坐席数一超 5，云管 Lite 的"单账号看板"不够用，天然升级 Pro/旗舰或增购坐席。

## 6. 续费与增购机制

### 6.1 年付折扣与预付策略

| 付费周期 | 规则 | 等效折扣 |
|---|---|---|
| 月付 | 年价 ÷ 10 ÷ 12 = 月价（如标准版 ¥1,667/月） | 12 个月付 = ¥20,000，年付即"10 个月费用"（83 折） |
| **年付（默认）** | 年价（¥2 万/¥4.5 万/¥8 万） | 基准 |
| 两年付 | 年价 × 2 × 0.85 | 85 折 |
| 三年付 | 年价 × 3 × 0.70 | 7 折 |
| 自动续费（预存/绑定） | 到期自动扣，年付 9 折 | 90 折 + 免流失 |

> to B 回款是生命线（01/03）：**默认只给年付**，月付需人工审核；渠道/企业单除外。

### 6.2 续费提醒漏斗

```
T-60 财务/销售邮件（大客户） → T-30 企微机器人 + 邮件
→ T-15 短信 + 控制台 banner → T-7 销售/CS 电话跟进
→ T-3 强提醒（倒计时弹窗） → D0 进入 7 天宽限（见 4.3）
```
- 续费率目标：订阅 65%、企业单 80%（对齐 03 假设）。90 天内不触发，但机制要在 MSE 期就位。

### 6.3 坐席增购与用量包预购

- **坐席增购**：任意时刻，按剩余天数折算即时生效（公式见 2.3），不延长订阅到期日；增购满到下一档（如 5→15 坐席）时建议直接升专业版（更划算）。
- **用量包预购**：1 万会话 ¥680 / 5 万会话 ¥3,000；随订阅期滚动，12 个月滚动窗口，到期作废（use-it-or-lose-it 驱动预购决策）；预购优先抵扣超量（见 3.3）。
- **管理账号增购**：¥600/账号/年，按剩余天数折算。

## 7. 防滥用与风控

### 7.1 License 防扩散

- **企业版闭源分叉**（对齐 02 G9/M5）：社区版（Apache 2.0）与商业版隔离；工作记忆、多账号治理、审计、云管为商业差异面。
- **设备指纹绑定**：坐席 License 绑定 CPU/主板/网卡/磁盘序列号 hash；Agent 每 5 分钟心跳上报。
- **并发心跳校验**：同时在线设备数 > 坐席数 → 拒签 + 告警 + 锁定（防一套 License 多机轮询）。

### 7.2 设备与离线校验

| 风控点 | 规则 |
|---|---|
| 设备数限制 | 1 坐席 = 1 设备；设备换绑月度 ≤2 次（客服换电脑/账号迁移），超次人工审核 |
| 离线授权 | 本地验签（非对称签名，私钥仅服务端持有）；固定有效期；防时钟回拨（记录最近运行时间戳，检测回拨即锁定）；离线授权仅云管旗舰，价格含管理服务费 |
| 断网宽限 | 72 小时离线宽限，超时降级"仅接管+只读"（见 1.3） |

### 7.3 试用防薅羊毛

- 手机号 + 企业微信/营业执照验证；**每营业执照限 1 次试用**；设备指纹黑名单。
- 试用期数据不可导出（防"试用即白嫖"）；试用到期强制付费解锁，不放水。
- 试用额度 = 标准版额度（5 万会话），防止试用期刷量。

### 7.4 账号/平台风控

- 单坐席日 300 会话、单账号主动触达拟人化节流（对齐 01 高风控项，防微信封号）。
- 超量硬封顶（基础额度 ×1.2）熔断，保护我方 API 成本。
- 安全基线（对齐 02 G8）：后台登录 + RBAC、数据与 Key 加密、TLS、日志脱敏——安全问卷不过关的大客户连 POC 都进不去。

## 8. 收费模式时间线：90 天最小闭环与后续演进

### 8.1 90 天内：最小可收费闭环（按周排期，对齐 02 W 里程碑）

| 周 | 交付物 | 验收 Gate |
|---|---|---|
| **W1–3** | **M5 License 体系**：企业版闭源分叉 + License 服务（试用 14 天/正式/续费）+ 在线心跳 + 72h 离线宽限 | 可发 14 天试用授权；校验拦截未授权实例 |
| **W1–3** | **收款基础**：对公账户、数电票开票通道、合同模板、落地页付费 CTA、支付商户号 | 客户能"付款→到账→开票"闭环 |
| **W3–6** | **云管 Lite**：激活/License 管理、账号级配置、单账号看板、基础告警 | 支撑首个付费客户交付（签约→上线 ≤3 天） |
| **W6–8** | **用量计量 v1（S3）**：会话/消息/接管计量 + 配额 + 用量报表 | 可出"基础额度+超量"账单；硬封顶生效 |
| **W8–10** | **云管 Pro**：集中看板/告警中心/审计/月度报告/Webhook | 增值溢价层可售；企业单法务闸门可过 |
| **W10–13** | 计费链路自动化 + 渠道结算准备（渠道码追踪） | 激活→付款→开票→签发 License 全程 ≤1 人日/单 |

**90 天验收（对齐创始人定向）**：
```
达标路径（订阅优先）：
  战略伙伴 10 家 × ¥1 万         = ¥10 万   （前 4 周签完，换案例 + 转介绍）
  标准版 40 家 × ¥2 万           = ¥80 万
  专业/旗舰 + 云管加购（≈5 家）    ≈ ¥6 万
  用量包 / 坐席增购 / 渠道          ≈ ¥4 万
  ─────────────────────────────
  合计 ≈ ¥100 万（签约口径）；回款 ≥ ¥60 万（90 天红线）
若按"50 单标准 + 10 战略"字面口径（50×2万 + 10×1万 = 110 万），本路径的"专业/旗舰+增购"即为达成 110 万的超额缓冲。
```

### 8.2 90–180 天：收费模式演进

| 演进项 | 内容 | 触发条件 |
|---|---|---|
| 预付费/用量混合 | 用量包预购规模化、月度弹性结算（先用后付 + 信用额度）、自动续费（9 折） | 用量计量稳定后 |
| 渠道结算 | 渠道码（channel token）追踪分账；渠道结算 = 标价 70%、分佣 30–50%；渠道白标（渠道 logo 云管后台） | 渠道出单（D31+ 启动） |
| 多租户 SaaS 云版 | 除客户侧值守机外的第二条交付路径，降低交付成本 | 对齐 02 阶段 2 |
| 计费系统正式化 | 账单/发票/税务自动化、与财务系统集成、企业单里程碑结算 | 付费客户 >30 后 |
| 企业单/私有化壳 | 同一 License/计量体系承载 MSE 私有化（¥6.8–12.8 万）与企业定制（02/03 详述） | 企业 POC 进商务 |
